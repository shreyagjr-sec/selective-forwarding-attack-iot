# Double Spending Detection with Network Observers and Peer Alerts

Explored double-spending detection in a JavaScript blockchain prototype using pending-transaction monitoring and a peer-alert concept. The report demonstrates transaction signing, mining rewards, balance updates, and rejection of suspicious transactions.

## Project type

Educational prototype

## Tools and topics

JavaScript, Node.js, elliptic-curve signatures, blockchain validation

## Work documented

- Implemented and documented block-hash and previous-hash validation in an educational blockchain.
- Demonstrated signed transactions and pending-transaction balance checks.
- Investigated peer alerts and handling of suspicious transaction sequences.

## Evidence and limitations

The report describes a simplified blockchain model. Its peer-alert and chain-reconstruction behavior is not evidence of production-ready consensus security. No scalability benchmarks or security proof are supplied.
