# Selective Forwarding Attacks in RPL IoT Networks

Investigated selective forwarding in simulated RPL networks by comparing normal operation, malicious nodes, and node mobility. The report describes a malicious node that drops every third received packet.

## Project type

Simulation project

## Tools and topics

Contiki OS, Cooja, RPL, C, packet captures

## Work documented

- Compared static benign, static malicious, and mobile-node scenarios.
- Documented node status, packet behavior, and power-consumption observations.
- Collected simulation screenshots and packet captures.

## Evidence and limitations

The supplied ZIP includes simulation source files and captures. Code is intentionally omitted from this portfolio for later upload. The included material does not establish a measured detection accuracy or a validated mitigation system.
