# Ransomware Impact on Data Integrity and Host Accessibility

Co-authored an analysis of ransomware as cryptographic coercion, focusing on how encryption, file manipulation, and interference with recovery mechanisms affect data integrity and access to systems.

## Project type

Collaborative research analysis

## Tools and topics

Ransomware literature review, host-behavior analysis, recovery and resilience assessment

## Work documented

- Examined infection pathways, hybrid encryption, and recovery disruption.
- Compared signature-based and behavior-based detection approaches.
- Discussed immutable backups, integrity monitoring, and layered defensive strategies.

## Evidence and limitations

The report is co-authored by Martin Inyang, Swathi Tathireddy, Shreya Gajjar, Ashma Bhandari, and Mass Shalash. Individual implementation ownership is not specified. Reported percentages lack sufficient raw data and experiment details for reproducible performance claims, so they are not used as portfolio achievements.
