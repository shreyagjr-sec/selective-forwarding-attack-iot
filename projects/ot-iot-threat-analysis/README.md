# Real Time OT IoT Network Security and AI Assisted Threat Analysis

An ongoing graduate project at Wright State University focused on a real-time pipeline for OT/IoT traffic capture, aggregation, PCAP reconstruction, and AI-assisted threat analysis.

## Status

In progress • 2026–present.

## Planned workflow

1. Capture OT/IoT network traffic.
2. Aggregate packets and flows and reconstruct PCAP evidence.
3. Prepare traffic for malicious-versus-benign analysis.
4. Evaluate latency, throughput, concurrency, and scalability.
5. Design feedback from threat analysis to alerting and potential firewall responses.
