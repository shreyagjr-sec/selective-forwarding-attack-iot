# Post Quantum Cryptography and Adoption Challenges

Reviewed post-quantum cryptographic approaches and the technical and organizational challenges of adopting them. The paper compares algorithm families and examines integration, performance, implementation security, and cryptographic agility.

## Project type

Literature review • December 2025

## Tools and topics

Cryptographic literature review, algorithm comparison, migration planning

## Work documented

- Compared CRYSTALS-Kyber, CRYSTALS-Dilithium, Falcon, SPHINCS+, and Classic McEliece as discussed in the submitted paper.
- Examined compatibility, key and signature sizes, and side-channel considerations.
- Discussed migration planning and organizational readiness.

## Evidence and limitations

This is a literature review, not an implemented cryptographic library or an original benchmark. Algorithm names follow the submitted paper; its standardization references require updating before using it as current deployment guidance.
